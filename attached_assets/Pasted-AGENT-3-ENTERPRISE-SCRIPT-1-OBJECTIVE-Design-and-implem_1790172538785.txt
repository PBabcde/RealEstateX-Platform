AGENT 3 – ENTERPRISE SCRIPT 1

OBJECTIVE

Design and implement the first production-grade Enterprise Core that will become the shared foundation for all future projects.

Projects that must ultimately run on this core:

- HFG
- Vastgoed Platform
- Energy Module
- Subsidy Module
- Deal Structuring
- Investor Module
- CRM
- SaaS

This is NOT a project-specific implementation.

This is the reusable Enterprise Core.

=================================================

REQUIRED ARCHITECTURE

=================================================

LAYER 1 – TRUST

Goal:

Guarantee data integrity and source trust.

Implement:

- CANONICAL sources
- SHADOW sources
- PAPER sources
- LIVE sources

Requirements:

- immutable identifiers
- source tagging
- source validation
- mixed-data detection
- boundary enforcement

No cross-source contamination allowed.

=================================================

LAYER 2 – IDENTITY

Goal:

Every object has exactly one immutable identity.

Support:

- User ID
- Property ID
- Deal ID
- Energy Report ID
- Subsidy Report ID
- Investor ID
- Audit Event ID

Implement:

- UUID architecture
- immutable IDs
- entity linking

=================================================

LAYER 3 – POSTGRESQL CORE

Goal:

Single enterprise database layer.

Create schemas for:

users
properties
deals
energy_reports
subsidy_reports
investors
audit_logs
crm_contacts

Requirements:

- SQLAlchemy
- Alembic migrations
- transaction safety
- indexing strategy

=================================================

LAYER 4 – AUDIT

Goal:

Every meaningful action becomes auditable.

Store:

timestamp
actor
action
entity
result

Requirements:

- immutable audit entries
- audit query layer
- filtering
- recovery tracking
- human-readable audit reports

=================================================

LAYER 5 – SECURITY

Goal:

Enterprise-grade protection.

Implement:

- JWT authentication
- role-based access control
- API keys
- secret management
- environment variables
- permission enforcement
- rate limiting
- input validation

Roles:

Admin
Operator
Analyst
Investor
User

=================================================

LAYER 6 – RECOVERY

Goal:

Survive failure.

Implement:

- backup service
- restore service
- rollback points
- disaster recovery hooks
- integrity verification

Requirements:

- audit-aware recovery
- recovery testing

=================================================
