# User guide

## Dashboard

The dashboard shows portfolio count, area, estimated valuation, rental yield,
and the current market direction.

## Objecten

Use **Object toevoegen** to add a property. Open a saved property to edit its
details or remove it. Required information includes address, property type,
construction year, living area, and energy label.

## Rekentools

- Valuation estimates an indicative value from area, energy label, and location
  factor.
- Rental analysis compares annual rental return and gross yield.
- Mortgage analysis calculates monthly payment and total repayment.

These are decision-support estimates, not legal, tax, valuation, or lending
advice.

## Markt

Market view shows the configured trend signal and period. Treat it as a
directional indicator and compare it with object-specific data.

## Suite

The Suite page shows the twenty Phase 2 modules and their current registry
status. The current visible status is a service registry status, not proof
that every module has a live production API route.

## Assistant and chat API

The API supports AssistantX questions and ChatBoxX sessions. Until
authentication and document retrieval are implemented, do not submit
confidential personal, tenant, contract, or financial documents.
